# Security / Data private context

- Для MVP достаточно минимизировать персональные и чувствительные данные и явно описать, где они хранятся.
- Проверяй риски загрузки файлов, prompt injection, утечки приватных документов и лишних прав доступа.
- Доступы должны соответствовать реальным ролям пользователей, даже если реализация пока простая.
- Не превращай MVP в долгий compliance-проект, но фиксируй риски, которые нельзя игнорировать архитектурно.

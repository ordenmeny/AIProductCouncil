# Security / Compliance private context

- Enterprise-клиенты ожидают роли доступа, аудит действий и понятную политику хранения данных.
- Для MVP достаточно минимизировать персональные данные и явно описать, где они хранятся.
- Проверяй риски загрузки файлов, prompt injection, утечки приватных документов и доступа между tenant-ами.
- SOC2/GDPR можно не реализовывать полностью в MVP, но нельзя игнорировать архитектурно.

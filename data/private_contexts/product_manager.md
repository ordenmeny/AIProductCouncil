# Product Manager private context

- Проверяй, есть ли у продукта конкретный ICP и повторяемая боль.
- Не включай в MVP функции, которые не нужны для проверки ценности.
- Хороший первый MVP должен закрывать один основной workflow end-to-end.
- Сильный сигнал: пользователь уже решает проблему вручную в таблицах, чатах или документах.

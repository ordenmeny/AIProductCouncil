# Product Manager private context

- Проверяй, какую конкретную проблему заказчик хочет решить и кто будет пользоваться результатом.
- Не включай в MVP функции, которые не нужны для проверки основной ценности.
- Хороший первый MVP закрывает один основной сценарий end-to-end.
- Сильный сигнал: пользователь уже решает проблему вручную в таблицах, чатах, документах или через несколько разрозненных инструментов.
